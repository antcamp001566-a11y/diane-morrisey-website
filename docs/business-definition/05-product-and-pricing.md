## Pricing philosophy `[Suggested]`

1. **Free is the product, not the trial.** The content core stays free. It's what earns the audience.
2. **Charge for depth, time and access**, never for what used to be free.
3. **Price from value delivered**, using benchmarks from comparable sites (doc 04), not from a revenue target.
4. **One offer at a time.** Add the next only when the current one is working.

## Roadmap `[Suggested]`

### Now (0–3 months): earn attention
- [ ] Choose the platform. `[Suggested]`: a simple builder (Squarespace or Wix) if Diane edits it herself; a static site (Astro + Netlify) if someone technical maintains it.
- [ ] Home, About/Story, Contact
- [ ] Content core launched with 3–5 pieces ready on day one

- **Exit metric:** returning visitors appear month over month

### Next (3–9 months): earn trust
- [ ] Newsletter, offered after content
- [ ] Reader feedback loop: one question in each newsletter
- [ ] "Work with Diane" page, if inquiries are arriving
- **Exit metric:** steady subscriber growth; readers replying

### Later (9+ months): let revenue follow
- [ ] First paid offering, only where the evidence trigger is met (table above)
- [ ] Partnerships and community
- **Exit metric:** revenue appears *without* return visits or replies dropping. If they drop, intent has drifted (doc 00).
