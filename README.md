# Diane Morrisey Website

A personal website for Diane Morrisey — New York Times best-selling author
of *You Got This!* and food creator behind "Cooking Real Food for Real
People." The site sells the book, hosts her recipes, showcases her press
coverage, and gives fans, brands, and media a way to get in touch.

Built with [Next.js](https://nextjs.org) and [Tailwind CSS](https://tailwindcss.com).

## Pages

- **Home** — hero with the book and a buy button, featured recipes, press logos
- **About** — Diane's story as a mom of 6 and author
- **Recipes** — searchable, filterable recipe collection
- **The Book** — details, reviews, and buy links for *You Got This!*
- **Press** — media features and press mentions
- **Contact** — business inquiry form and email list signup

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.
